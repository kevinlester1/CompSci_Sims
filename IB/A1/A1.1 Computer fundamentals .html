Unit A.1: Conceptual & Factual Review

Test your knowledge with these conceptual and factual questions derived directly from the 2027 DP Computer Science syllabus (Theme A).

Factual Questions

1. Identify the components of the CPU.

Answer: The main components include the Arithmetic Logic Unit (ALU), the Control Unit (CU), and Registers (such as the PC, MAR, MDR, IR, and Accumulator).

2. Define the purpose of the Memory Address Register (MAR).

Answer: The MAR holds the memory address of the data or instruction that is to be fetched from, or written to, primary memory.

3. State three functions of an operating system.

Answer: Memory management, file system management, device management, process scheduling, security management, and providing a graphical user interface (GUI).

4. Describe the differences between RAM and ROM.

Answer: RAM (Random Access Memory) is volatile and stores data and instructions for currently running programs. ROM (Read-Only Memory) is non-volatile and permanently stores essential boot-up instructions (firmware/BIOS) that cannot be easily altered.

5. State the purpose of cache memory.

Answer: Cache memory is a small, ultra-fast memory located inside or close to the CPU. Its purpose is to store frequently used data and instructions, reducing the time the CPU spends fetching data from the slower main memory (RAM).

6. Identify three types of secondary storage.

Answer: Magnetic (e.g., Hard Disk Drives/HDD), Solid State (e.g., Solid State Drives/SSD, flash drives), and Optical (e.g., CDs, DVDs).

7. Outline the three primary models of cloud computing.

Answer: SaaS (Software as a Service) provides ready-to-use software accessed via a browser; PaaS (Platform as a Service) provides development frameworks/tools for programmers; IaaS (Infrastructure as a Service) provides raw virtualized hardware (servers, storage) where the user manages the OS and apps.

Conceptual Questions

1. Explain how pipelining improves CPU performance. (HL)

Answer: Pipelining overlaps the fetch, decode, and execute stages of different instructions. Instead of waiting for one instruction to completely finish, the CPU can fetch a second instruction while the first is being decoded, significantly increasing overall instruction throughput per clock cycle.

2. Evaluate the use of polling versus interrupt handling.

Answer: Polling requires the CPU to continuously check a device's status, wasting processing overhead and power if events are rare. Interrupts allow the CPU to perform other tasks until a hardware device signals it needs attention. Interrupts are more efficient for unpredictable events, while polling might be useful for continuous, predictable high-speed data transfers.

3. Distinguish between an interpreter and a compiler. (HL)

Answer: A compiler translates the entire source code into machine code in one go before execution, producing a standalone executable that runs quickly but requires recompilation if changed. An interpreter translates and executes the source code line-by-line in real time, making debugging easier but resulting in slower overall execution.

4. Explain how a CPU differs functionally from a GPU. (HL)

Answer: A CPU has a few highly complex cores designed for general-purpose, sequential processing and fast execution of single tasks. A GPU features thousands of simpler, smaller cores optimized for parallel processing, making it highly efficient at handling multiple simple computations simultaneously (ideal for rendering graphics or training machine learning models).

5. Compare lossy and lossless data compression.

Answer: Lossy compression significantly reduces file size by permanently removing non-essential data, which is acceptable for audio/video but lowers quality. Lossless compression reduces file size by identifying data patterns (like RLE) without losing any actual information, allowing the original file to be perfectly restored.

6. Compare FCFS and Round Robin scheduling approaches.

Answer: First-Come First-Served (FCFS) executes processes in the exact order they arrive, which is simple but can cause long wait times if a large process arrives first. Round Robin allocates a fixed time slice (quantum) to each process in turn, cycling through them, which ensures fairness and responsiveness but adds switching overhead.

7. Explain the role of the OS in managing resource deadlocks. (HL)

Answer: Deadlocks occur when two or more processes are blocked forever, each waiting for a resource held by the other. The OS manages this by employing strategies like deadlock prevention (ensuring wait conditions can't occur), deadlock avoidance (dynamically checking resource allocation states), or deadlock detection and recovery (aborting conflicting processes).

Hardware Explanations

  • ALU & CU: ALU performs math/logic; CU directs operations and data flow.
  • Registers:
    • PC: Holds address of next instruction.
    • MAR: Holds address to fetch/write from memory.
    • MDR: Holds actual data fetched/waiting to be written.
    • IR: Holds current instruction being decoded.
    • Accumulator: Stores intermediate arithmetic/logic results.
  • Buses:
    • Address Bus: Carries the memory location to be read/written (Unidirectional).
    • Data Bus: Carries actual data/instructions between CPU and memory (Bidirectional).
    • Control Bus: Carries command signals like Read, Write, and Clock synchronization.
  • Cores & Processors: A core is an independent processing unit in a CPU.
    • CPU: Few powerful cores optimized for sequential, general-purpose tasks.
    • GPU (Graphics Processing Unit): Thousands of simpler cores designed for highly parallel processing.
  • Instruction Pipelining (Deep Dive)

    Sequential vs. Pipelined: In a basic CPU, an instruction must go completely through the Fetch, Decode, and Execute stages before the next instruction can begin.

    How Pipelining Works: Instruction Pipelining overlaps the execution of multiple instructions to increase throughput. As soon as Instruction 1 finishes Fetching and moves to Decode, the Fetch unit is freed up to grab Instruction 2.

  • Memory Types:
    • RAM: Volatile working memory storing active programs and data.
    • ROM: Non-volatile memory storing essential bootup instructions (BIOS).
    • Cache: Small, ultra-fast memory near the CPU storing frequently used data (L1, L2, L3).

Storage & Cloud Explanations

  • Secondary Storage: Non-volatile, long-term storage.
    • Magnetic (HDD): High capacity, low cost, uses moving mechanical parts.
    • Solid State (SSD): Flash memory, no moving parts, faster, durable, higher cost.
    • Optical (CD/DVD): Lasers read/write data on a disc. Very portable, low capacity.
  • Data Compression: Reducing file sizes to save storage space and transmission time.
    • Lossy: Permanently removes non-essential data.
    • Lossless: Reduces size without losing any data; perfectly restorable.
  • Cloud Computing Models:
    • SaaS: Software as a Service.
    • PaaS: Platform as a Service.
    • IaaS: Infrastructure as a Service.
