Network Fundamentals

Factual Questions (AO1)

Test your knowledge and understanding of fundamental A2.1 definitions and concepts.

A LAN (Local Area Network) connects devices within a limited geographical area (like a home or school), is typically owned by a single organization, and offers high speed and low latency. A WAN (Wide Area Network) spans large geographical distances (like cities or countries), connects multiple LANs, and often relies on leased telecommunication lines (ISPs), typically resulting in lower bandwidth and higher latency.
From top to bottom (data generation to transmission): Application Layer, Transport Layer, Internet Layer, and Network Interface (Access) Layer.
A router operates at the Internet Layer (Layer 3) to connect distinct networks together. It inspects the destination IP address of incoming data packets and uses routing tables to determine the most efficient path to forward the packet toward its final destination.
TCP (Transmission Control Protocol) is connection-oriented, requiring a 3-way handshake before transmitting. It guarantees ordered delivery via acknowledgments, making it reliable but slower. UDP (User Datagram Protocol) is connectionless and sends datagrams without verifying receipt. It is unreliable but significantly faster, making it ideal for streaming video or VoIP.
DHCP (Dynamic Host Configuration Protocol) automatically assigns dynamic IP addresses, subnet masks, and other network configurations to devices as they join a network, eliminating the need for manual, static IP assignment.

Conceptual Questions (AO2/AO3)

Apply, analyse, and evaluate network concepts in real-world scenarios.

Circuit switching requires a dedicated, unbroken physical path for the duration of a connection, which wastes resources when idle. Packet switching segments data into small packets that are routed independently across shared, dynamic paths. This optimizes network bandwidth, handles congestion gracefully, and provides fault tolerance if a single link fails.
  • Advantages: The VPN encrypts all data, creating a secure "tunnel" that prevents Man-in-the-Middle (MitM) attacks or eavesdropping on insecure public Wi-Fi. It authenticates the user, securely extending the corporate LAN to the remote machine.
  • Disadvantages: It requires client software and adds processing overhead (encryption/decryption), which can increase latency and slightly reduce overall transmission speed.
Abstraction allows each layer of the TCP/IP model to focus solely on its specific task (e.g., routing, reliability, physical transmission) without needing to understand the internal workings of the other layers. A web browser (Application Layer) doesn't need to know if the data travels via fiber optic or Wi-Fi (Network Interface), enabling diverse hardware and software to interoperate seamlessly.
Autonomous vehicles process massive amounts of sensor data in real-time. Sending this data to a centralized Cloud infrastructure for processing introduces unacceptable latency (delay) that could cause accidents. Edge computing places processing power locally within the vehicle (or at nearby cell towers), allowing for instant decision-making and reducing overall network bandwidth usage.

A2.1 Glossary of Terms

Key vocabulary and definitions for Network Fundamentals.

LAN (Local Area Network)

A network connecting devices within a limited geographical area, such as a school or home. Typically owned by a single organization, offering high speed and low latency.

WAN (Wide Area Network)

A network spanning a large geographical distance, connecting multiple LANs together. The Internet is the largest example of a WAN.

PAN (Personal Area Network)

A network covering a very small area (usually within 10 meters), primarily for connecting personal peripheral devices via Bluetooth or Zigbee.

VPN (Virtual Private Network)

A service that creates a secure, encrypted "tunnel" over a public network, ensuring data confidentiality and allowing secure remote access to corporate LANs.

Router

A Layer 3 (Internet layer) device that directs data packets between entirely different networks using logical IP addresses and routing tables.

Switch

A Layer 2 (Network Interface layer) device that connects devices on the same LAN. It uses a MAC address table to forward frames only to specific destination ports.

Gateway

A node that serves as an entrance and exit point between differing networks. It actively translates different protocols and architectures so incompatible networks can communicate.

TCP (Transmission Control Protocol)

A connection-oriented, reliable protocol that guarantees data delivery via a 3-way handshake and retransmission of lost packets. Used for HTTP, HTTPS, and email.

UDP (User Datagram Protocol)

A connectionless, fast protocol that blasts packets without verifying receipt. Unreliable but ideal for real-time video streaming, VoIP, and gaming.

DHCP (Dynamic Host Configuration Protocol)

An application layer protocol that automatically assigns dynamic IP addresses and other network configurations to devices joining a network.

HTTP & HTTPS

HTTP transmits unencrypted web data. HTTPS (Secure) encrypts the data to protect sensitive info. Both are Application Layer protocols that rely on TCP.

Packet Switching

The process of breaking data into small, manageable blocks (packets) that are routed independently across dynamic network paths and reassembled at the destination.

Encapsulation

The process of wrapping data with necessary header information (like ports, IP addresses, and MAC addresses) as it passes down the layers of the TCP/IP stack.

Edge Computing

A distributed computing framework that brings computation and data storage closer to the sources of data. This drastically reduces latency for real-time applications (e.g., autonomous vehicles).

MAC Address

Media Access Control address. A unique, physical, 48-bit hard-coded address assigned to a Network Interface Card (NIC) by the manufacturer.

IP Address

Internet Protocol address. A logical numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.
