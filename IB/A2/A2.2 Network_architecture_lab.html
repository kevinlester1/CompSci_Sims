A2.2.3 Networking Models

Compare how data and processing are distributed. Real-world applications vary based on the model's benefits and drawbacks.

Client-Server

Centralized control, easier to secure and backup (e.g., Web Browsing, Email Services, Online Banking). Prone to bottlenecks.

Peer-to-Peer (P2P)

Decentralized, highly scalable, no single point of failure (e.g., File Sharing, VoIP Services, Blockchain). Harder to secure centrally.

A2.2.4 Segmentation

Network segmentation involves dividing a network into smaller zones. Using physical segmenting, logical subnetting, or Virtual Local Area Networks (VLANs) improves network performance and security. It reduces congestion (by limiting broadcast domains) and allows administrators to manage network resources efficiently.
